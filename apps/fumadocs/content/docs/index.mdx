## Core Highlights

- **Modern Kanban & 2-Column Inspector** – Drag-and-drop cards and columns with dedicated drag handles, spring-pop column animations, list duplication, inline title/description editing, and tactile "Mark Complete" pill toggles.
- **Universal Share Links & Invites** – Shareable role-specific invite tokens (Member or Viewer) with public preview and auto-acceptance for guests and existing users.
- **Team Workspaces** – Organize boards into workspaces with role management (Owner, Admin, Member), email invitations, and owner-managed workspace deletion.
- **Batch Board Management** – Multi-select owned boards for batch deletion or delete single boards directly from card menus.
- **Custom Fields & Automations** – Board custom fields (5 types: Text, Number, Date, Select, Checkbox) and automated due-date reminders via scheduled Convex cron jobs.
- **Viewer Role Support** – Safe read-only mode across boards, lists, cards, attachments, checklists, and comments.
- **Full Board Import / Export** – Backup boards to JSON and restore into new boards with complete card hierarchies and custom fields.
- **Admin Panel** – Manage user roles with preview confirmation dialogs, loading indicators, and user deletion.
- **Security Hardened** – Protected internal mutations, HTML-escaped emails, strict relative URL validation, rate limiting, and cross-board integrity checks.

## Quick Start

```bash
bun install
bun run dev:setup
bun run dev
```

Open [http://localhost:3001](http://localhost:3001) to view the web app, or [http://localhost:4000](http://localhost:4000) for the documentation site.
