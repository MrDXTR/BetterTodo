## Tech Stack

| Layer   | Technology                 |
| ------- | -------------------------- |
| Frontend | React 19, TanStack Router, TailwindCSS, shadcn/ui |
| Backend | Convex (BaaS)              |
| Auth    | Better Auth (email + Google OAuth) |
| Styling | TailwindCSS                |
| Drag & Drop | @hello-pangea/dnd     |

## Quick Start

```bash
bun install
bun run dev:setup
bun run dev
```

Open [http://localhost:3001](http://localhost:3001) to use the app.
